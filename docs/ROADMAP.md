# MTF Roadmap

更新日期：2026-08-10

## 产品目标

同一套 Typst 内容稳定产出三类东西：

- HTML：单文件离线模板站，赛前检索、赛中复制；
- PDF：ICPC 线下赛打印速查，彩色/黑白 × 竖排/横排四个版式；
- 验证：书里印的每一段代码都有机器背书——官方数据 AC，
  或至少通过语法编译门禁。

## P3：发布可靠性

- [ ] 构建指纹：产物内嵌 git rev 与日期，赛场可辨版本

## 验收基线

- `mtf render` 产出 1 HTML + 4 PDF，全部通过质量门禁；
- `mtf verify` 全量 AC 且未覆盖模板语法编译全部通过，退出码可信；
- 每个新模板入库时：catalog 登记 + 官方验证或明示未验证 +
  语法门禁通过。
