## 新增 A：动态区间 MEX → 相邻出现间隙 → 二维矩形最小值

对每个候选值 `v ∈ [0,n]`，维护其出现位置的有序集合，并放入哨兵 `0`、`n+1`。对于查询区间 `[l,r]`：

> `v` 没有出现，当且仅当 `v` 的某对相邻出现位置 `i<j` 满足 `i<l` 且 `r<j`。

于是把每个间隙变成带权点 `(i,j,v)`，查询矩形

```text
x ∈ [0,l-1], y ∈ [r+1,n+1]
```

中的最小权值，答案就是区间 MEX。

一次 `a[p]: old → new` 只产生常数个变化：旧值的两个间隙合并，新值的一个间隙拆成两个。因此序列修改会转成 `O(1)` 个二维点增删。

它暂定 A 而不是 S，因为真正落板子还差三件事：选定并验证动态二维矩形最小值结构；支持删除和重数；补齐 `old=new`、边界哨兵、同坐标不同权值等测试。完成这些即可复核为 S。

它与 AlgoWiki #171“存在性二维数点只维护另一维最值”在数据结构思想上相关，但不是重复；与 #38“排列中 MEX 与 min 的转化”只是共享 MEX 关键词，问题模型不同。
